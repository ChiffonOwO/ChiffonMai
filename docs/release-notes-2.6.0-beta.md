# ChiffonMai 2.6.0

这次更新主要围绕页面观感、播放体验、成绩数据和日常使用便利性进行改进。

## 更舒服的页面体验

- 大量功能页重新整理了布局，浅色模式更加清爽，减少了突兀的白色浮层。
- 补充了深色模式适配，弹窗、加载页面、服务器状态等页面在夜间也能保持协调。
- 统一了页面标题、背景、空状态提示和常用按钮的样式。
- 搜索筛选条件的展开和收起现在都有过渡动画。
- 页面切换、排行类型切换、数据源切换等操作增加了更自然的淡入淡出效果。
- 优化了多个页面的文字大小、间距和对齐方式，减少标题被截断或内容拥挤的情况。

## 随身听和歌曲功能

- 随身听支持预览前后歌曲，可以滑动曲绘切换歌曲。
- 切歌、播放和暂停增加了动画，播放页的操作反馈更加清晰。
- 支持将歌曲下载到手机文件管理器可以找到的目录，下载文件名为“歌名.mp3”。
- 下载完成后会显示更清晰的提示窗口，并可以复制保存路径。
- 新增下一首播放队列，并会记住队列内容。
- 随机抽歌支持用加减控件选择抽取数量。
- 随机抽歌结果改为歌曲卡片，显示曲绘、歌曲类型、歌名、艺术家和各难度定数。
- 歌曲搜索支持查看和重复使用搜索历史。
- 歌曲详情页的定数历史和可游玩地区信息进行了修正，减少同名歌曲匹配错误。

## 成绩、排行和段位

- Rating、拟合 Rating、平均成绩和特殊排行榜的切换动画与交互进行了统一优化。
- 修复特殊排行榜联网刷新后仍显示旧提示的问题。
- 修复宴会场歌曲被错误计入理想 Best50 的问题。
- 段位表新增“未挑战、不合格、合格、赤合格”四种完成状态。
- 段位详情页支持记录总达成率，并优化了状态选择和保存体验。
- KaleidXScope 的所有相关页面增加日期进度显示。
- KaleidXScope 支持显示多个时间段、难度和血量信息，并高亮当前时间段。
- 难度信息增加对应的难度颜色，时间段摘要更加易读。

## 新增和增强的功能

- 新增出勤转盘，出勤与不出勤区域交替排列，可调整区域数量并自动记住设置。
- 全球音游街机地图支持附近机厅自动聚合，缩放地图时会平滑展开和收起。
- 新增加载语录管理，支持本地语录和云端语录切换。
- 增加日志导出功能，遇到问题时可以更方便地提供排查信息。
- 支持开发者下载赞赏码图片。
- 服务器状态页面改用最新状态数据，并标注数据来源。
- About 页面重新设计，新增特别致谢、捐献致谢和相关服务链接。
- 段位表、谱面代码、OCR、收藏夹等页面的成功提示和错误提示更加统一。

## 其他改进

- 优化登录、数据同步和刷新数据时的等待体验。
- 提升歌曲、曲绘和排行榜数据更新的速度与稳定性。
- 修复部分页面首次打开时短暂无法操作的问题。
- 修复部分页面切换选项卡时卡顿、重复加载和返回异常的问题。
- 改进 Android 返回手势、高刷新率和谱面播放页的稳定性。
- 统一导出文件的保存位置，并在无法保存到公开目录时给出明确提示。
