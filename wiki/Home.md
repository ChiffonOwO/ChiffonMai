## 1. 项目简介

- **项目名**：ChiffonMai（基于 Flutter 工程 `my_first_flutter_app`）
- **版本**：当前 `1.12.1+34`
- **支持平台**：Android（iOS 端暂未发布）
- **技术栈**：Flutter / Dart，第三方 API 包括水鱼查分器、落雪咖啡屋、DXRating.net、AWMC 服务器状态、NearCade 等。
- **架构**：以 `HomePage` 为入口，按功能分类进入各 Page；网络层通过 `ApiUrls` + `ApiClient` 管理；数据通过 `manager/` 下的 Manager 类做本地缓存。

```text
lib/
├── api/           // API URL、常量配置
├── constant/      // 缓存键、版本列表等常量
├── entity/        // 数据模型
├── manager/       // 缓存 / 数据管理
├── page/          // 各功能页面
├── service/       // 业务服务
├── utils/         // 通用工具（主题、缓存、解码等）
├── widgets/       // 公共组件
└── main.dart      // 应用入口
```

## 3. 快速开始

```bash
# 1. 拉取依赖
flutter pub get

# 2. 检查环境
flutter doctor

# 3. 运行到已连接的设备 / 模拟器
flutter run

# 4. 打包 Android APK（调试版）
flutter build apk --debug

# 5. 打包 release APK
flutter build apk --release

# 6. 打包 Android App Bundle
flutter build appbundle --release
```

> 仓库已附带 `build_apk.ps1`，在 Windows PowerShell 环境下可直接运行：
> ```powershell
> ./build_apk.ps1
> ```

### 3.1 必需配置（部分功能依赖）

在项目根目录创建 `.env.local` 文件（仓库中已存在示例），用于：

- 配置自家后端 / OAuth 代理相关密钥；
- 切换 Debug/Release 环境。

若仅做本地运行 / 学习代码，可保留默认 `.env.local`。

## 5. 常用功能使用指南

### 5.1 登录水鱼账号

很多功能（成绩查询、Best50、牌子进度等）需要先登录水鱼查分器。

1. 进入 `首页 → 系统 → 登录水鱼`。
2. 选择登录方式：
   - **ImportToken 登录**：在水鱼网页端获取 `import_token`，粘贴到 App 中（适合日常使用，推荐）。
   - **二维码登录 / 密码登录**：通过水鱼 OAuth 流程登录。
3. 登录成功后，功能页会自动使用账号数据。
4. 注销：`首页 → 系统 → 登出账号`。

> 水鱼登录走自家后端 OAuth 代理（见 `ApiUrls.ProberBaseUrl`），App 不直接保存你的密码。

### 5.2 乐曲查询

1. 进入 `首页 → 曲库与数据 → 乐曲查询`。
2. 顶部搜索框支持：
   - 曲名（中/日/英/罗马音）
   - 曲师 / 别名 / 标签
   - 定数区间、BPM、版本等过滤
3. 点击单首歌曲进入 `SongInfoPage`，可查看：
   - 基础信息（类型、BPM、版本等）
   - 各难度（Basic / Advanced / Expert / Master / Re:Master）定数与谱面信息
   - **maidata.txt**（进入 `SongMaidataPage`，便于研究谱面）
   - **谱面播放**（进入 `ChartPlayPage`，应用内解析并播放）

### 5.3 成绩查询

1. 进入 `首页 → 曲库与数据 → 成绩查询`。
2. 输入水鱼用户名，或选择已登录账号直接进入。
3. 支持按乐曲、谱面难度、版本、达成率、Rating 区间等筛选。
4. 支持排序、收藏、跳转到单曲详情。

### 5.4 Best50 查询

1. 进入 `首页 → Best50 与排行榜 → Best50 查询`（需登录水鱼）。
2. 自动拉取个人游玩数据，计算 Rating 前 50 的成绩。
3. 支持：
   - 导出为长图（用于分享）
   - 查看单曲详情
   - 切换 **拟合 Best50** / **个性化 Best50**（锁血 50、AP50、按定数等筛选）
4. 多维度版本：
   - `Best50Page`：常规
   - `DiffBest50Page`：按定数差值
   - `PersonalizedBest50Page`：按个性化标签
   - `PersonalizedDiffBest50Page`：按个性化 + 定数差值

### 5.5 牌子进度查询

1. 进入 `首页 → 曲库与数据 → 牌子进度`。
2. 选择难度（Basic / Advanced / Expert / Master / Re:Master）和目标牌子（極 / 将 / 神 / 裏極 等）。
3. 自动展示达成进度，缺失曲目按版本分组展示。
4. 支持 **导出图片**（`PaiziProgressConvertToImgService`）一键生成长图分享。

### 5.6 单曲 Rating / 达成率计算

#### 5.6.1 单曲 Rating 计算
1. 进入 `首页 → 实用工具 → 单曲 Rating 计算`。
2. 选择曲目 + 难度，输入达成率。
3. 系统按 `Rating = 定数 × 达成率系数` 计算单曲 Rating，并给 SSS+ / SSS / SS 等评价预估。

#### 5.6.2 达成率计算
1. 进入 `首页 → 实用工具 → 达成率计算`。
2. 输入 Perfect / Great / Good / Miss / 空击 命中数。
3. 系统按官方公式精确计算达成率。

#### 5.6.3 达成率反推
1. 进入 `首页 → 实用工具 → 达成率反推`。
2. 输入已知达成率与命中数，反推可能的绝赞 / 不绝赞判定组合。

### 5.7 推荐类功能

App 提供 4 种推荐方式：

| 入口 | 推荐逻辑 |
| :--- | :--- |
| 基于标签推荐 | 根据你常玩曲目的谱面标签（来自 DXRating）推荐同标签新曲 |
| 基于目标 Rating 推荐 | 输入目标 Rating，推荐能达到的曲目 |
| 基于定数区间推荐 | 输入定数区间，筛选适合上分的曲目 |
| 每日推荐 / 随机乐曲 | 基于已玩记录每天推荐未玩曲目，或随机抽 1~4 首 |

### 5.8 猜歌游戏

`首页 → 猜歌游戏` 提供 7 种玩法：

1. **无提示猜歌**：凭记忆猜曲名。
2. **根据部分曲绘猜歌**：随机截取部分曲绘。
3. **根据模糊曲绘猜歌**：随机截取并打码曲绘。
4. **根据歌曲片段猜歌**：播放随机音乐片段。
5. **根据别名猜歌**：根据常用别名。
6. **舞萌开字母**：逐字揭示，考验对曲目细节了解。
7. **多人猜歌游戏**：WebSocket 实时对战，与好友同台竞技（`MultiplayerLobbyPage`）。

### 5.9 曲绘识别 / 自定义谱面播放

- **曲绘识别**：`首页 → 实用工具 → 曲绘识别`，调用 `mobile_scanner` / `image_picker` 拍照，调用后端识别服务匹配歌曲。
- **自定义谱面播放**：`首页 → 实用工具 → 自定义谱面播放`，需要提供：
  - `maidata.txt`
  - 曲绘（可选）
  - 音源（可选）
  - App 内置 `simai_flutter` 解析与播放器。

### 5.10 同步成绩到水鱼 / 落雪

1. 进入 `首页 → 系统`。
2. 选择 `同步成绩到水鱼` 或 `同步成绩到落雪`。
3. 支持的方式：
   - **机台 QR 码**：使用舞萌机台导出的 QR 码直接导入。
   - **DXNet Bot**：通过 `Maimai Score Hub`（`maimai.bakapiano.com`）后台同步。
4. 同步后会在水鱼 / 落雪端生成对应游玩记录。

### 5.11 主题 / 数据备份

- **主题切换**：`首页 → 系统 → 浅色/深色模式`，跟随系统 / 浅色 / 深色 / 纯黑。
- **数据备份**：`首页 → 系统 → 数据备份`，可导出/导入本地缓存（收藏夹、个性化配置、收藏的功能、主题等）。

## 6. 常见问题 FAQ

**Q1：首次启动很久加载不出来？**
A：App 首次会拉取并缓存全量曲库、别名、标签等数据（约 10 万首曲目），建议在 Wi-Fi 下首次启动。

**Q2：登录水鱼失败？**
A：检查 `.env.local` / 网络；如使用密码登录请确认水鱼未开启二次验证。也可使用 ImportToken 登录绕过密码。

**Q3：Best50 数字和我水鱼网页不一致？**
A：App 拉取的是 OAuth 代理返回的最新数据；若水鱼刚同步请点 `首页 → 系统 → 刷新数据`。

**Q4：iOS 端在哪下载？**
A：iOS 端正在协调发布，暂未上线。

**Q5：谱面播放没声音？**
A：检查系统静音 / 媒体音量；自定义谱面需要提供音源；部分曲目音源来自落雪服务器，海外网络可能受限。

**Q6：怎么更新到最新版本？**
A：`首页 → 系统 → 检查更新`，或前往发布页下载新版 APK。

**Q7：贡献代码要注意什么？**
A：
- Dart 代码遵循 `analysis_options.yaml`；
- 新增功能请在 `lib/utils/FeatureRegistry.dart` 注册；
- 涉及第三方 API 的改动请同步更新 `lib/api/ApiUrls.dart`。
